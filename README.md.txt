# Safety-Critical RISC-V SoC for HV Battery Systems

M.Tech Dissertation Project

## Objective

Design and FPGA-based prototype of a configurable safety-oriented
RISC-V SoC with hardware safety mechanisms and controlled fault
injection, demonstrated using an HV battery monitoring workload.

## Repository Structure

- `rtl/` – RTL design
- `tb/` – SystemVerilog testbenches and assertions
- `sw/` – RISC-V software/workload
- `data/` – Battery input data
- `constraints/` – FPGA constraints
- `vivado/` – Vivado project files
- `docs/` – Design documentation

## Processor

Ibex RISC-V Core

## FPGA

Xilinx Artix-7 based FPGA platform
